# 8회차 — 고객 readout 발표 (10월 15일 목 21:00)

마지막 회차는 발표입니다. 한 사람당 12분. 강사가 고객(CX팀장 · 정보보호팀장) 역할로 질문합니다. 새 코드는 없고, 7회차까지 만든 것을 자기 노트북에서 보여 줍니다.

## 발표 12분의 구성

| 분 | 무엇 | 화면 |
|---|---|---|
| 0~5 | **데모.** 아래 질문 넷을 순서대로 보낸다. 터미널(`make api-ask`)이든 브라우저(`http://localhost:8000/?key=change-me`)든 편한 쪽 | 터미널 또는 브라우저 |
| 5~9 | **readout 1쪽.** `docs/readout_1p.md` 를 화면에 띄우고 1절부터 7절까지 읽는다. 숫자마다 출처 파일을 말한다 | 마크다운 미리보기 |
| 9~12 | **고객 질문.** 고정 질문 둘 + 데모에서 본 것 하나 | — |

**고정 질문 둘**은 미리 압니다. 답을 준비하세요.
1. "틀린 답을 하면 누가 책임지나요?" → 고지 · 근거 인용 · 감사 로그 · 상담사 최종 확인으로 답합니다.
2. "이게 우리 내부망에 들어올 수 있나요?" → 배포 모드 셋과 오프라인 번들로 답합니다. 보안 답변서 Q6 이 그대로 답입니다.

## 데모 질문 넷 (강사가 4축으로 O/X 를 적습니다)

`docs/templates/demo_checklist.md` 의 추천 질문 그대로입니다. 미리 한 번씩 보내 보고 어떤 답이 나오는지 알아 두세요.

| 축 | 질문 | 보는 것 |
|---|---|---|
| 근거 인용 | 하나은행 여신거래기본약관 제7조에서 기한이익 상실 통지는 며칠 전까지 해야 하나요? | 문서 · 조항 · **시행일**이 붙는가. 2013년 판과 2024년 판 중 어느 쪽을 인용했는지 말할 수 있는가 |
| 미답변 | ABL 인터넷암보험을 5년 뒤 해지하면 해약환급금이 얼마인가요? | 숫자를 만들지 않고 거절하는가. 이유에 조항을 대는가 |
| 계산 | 하나은행 3년 만기 주택담보대출을 2년 후 1억원 상환하면 중도상환해약금은 얼마인가요? | 466,666원(윤년 467,518원). 요율 1.4% 를 어느 문서에서 읽었는지, 어떤 절사 규칙인지 |
| 운영 | (질문이 아니라 화면) `docker compose ps` 또는 `make api` 가 떠 있는 상태, `tail -1 logs/audit.jsonl` 한 줄 | 서비스가 떠 있는가. 로그에 원문이 없는가. "Qdrant 가 죽으면 무엇부터 하나요?"에 답할 수 있는가 |

첫 요청은 콜드 스타트라 30초가 넘습니다. **발표 전에 질문 하나를 미리 보내 두세요.** 모델이 올라와 있으면 질문당 15초 안팎입니다.

## readout 1쪽 — 숫자는 어디서 오나

`docs/templates/readout_1p.md` 를 `docs/readout_1p.md` 로 복사해 채웁니다. 빈칸마다 출처 파일이 정해져 있습니다.

| 절 | 빈칸 | 파일 · 칸 |
|---|---|---|
| 1 문제 | 현재 워크플로우 · 소요 시간 | 1회차 디스커버리 노트(`docs/discovery_note.md`) |
| 2 무엇을 만들었나 | 문서 수 · 쪽 | `data/documents.csv` 행 수 |
| | 청크 수 | `data/ingest_report.json` 의 `chunks` |
| | 평가 문항 | `data/golden/seed_golden.jsonl` 40문항 8유형, `calc_golden.jsonl` 15, `adversarial.jsonl` 5 |
| | 배포 형태 | `docker-compose.yml` 의 서비스 셋 |
| 3 성능 | Recall@5 · MRR · 평균 지연 세 열 | `results/compare.csv` 의 `전체` 행 |
| | 유형별 한 줄 | 같은 파일의 유형 행 (6회차 과제 `docs/eval_report.md` 가 있으면 그대로) |
| | 미답변 정확도 · 오거절률 | `results/agentic.json` 의 `abstain_accuracy` · `false_refusal_rate` |
| 4 계산 정확도 | 일치 문항 수 | `results/calc_e2e.json` 의 `matched` / `n` |
| 5 한계 | 셋 | 미답변형 문항, 사람 검토 큐 문서, 계산 안 되는 문항에서 |
| 6 비용 | 월 추정 | `results/roi.json` 의 `monthly`. 가정값에는 "가정" |
| 7 다음 단계 | 안 둘 | 자기 생각. 7회차 배포 모드 표의 2 · 3 이 후보 |
| (운영) | 응답 시간 예산 | `results/api_bench.json` 의 `latency_ms_p95` · `cost_krw_avg`, 스트림 첫 글자 |

규칙 하나. **모든 숫자에 출처와 기준일을 붙입니다.** 출처 없는 숫자는 지웁니다.

## 수업 전에 할 것

1. `docs/readout_1p.md` 를 채워 포크에 푸시합니다(README 도 한 번 읽어 보고 고칠 것이 있으면 같이).
2. 수업 시작 전에 서버를 띄웁니다. `make api`(둘째 터미널) 또는 `make compose-up`. `curl -s localhost:8000/health` 의 `points` 가 3,000 넘는지 봅니다.
3. 질문 하나를 미리 보내 모델을 올려 둡니다.
4. 화면 공유 순서를 정해 둡니다. 터미널(또는 브라우저) → `docs/readout_1p.md` 미리보기.
