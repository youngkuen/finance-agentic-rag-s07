# 고객 readout 1쪽 — 상담사 약관 조회 AI PoC (한빛저축은행, 가상)

> 규칙 하나: **모든 수치에 출처와 기준일을 붙인다.** 측정값은 2026-10-13 이 폴더에서 실제 모델(gpt-5.4-mini + nano)로 돌린 결과 파일이고, 가정값에는 "가정"이라고 적었다.

## 1. 문제 (3줄)

- 지금: 콜센터 상담사가 고객 문의를 받으면 약관·상품설명서 PDF 를 열어 해당 조항을 눈으로 찾는다. 신입은 어느 문서의 어느 조항인지부터 모른다 (1회차 브리프 `docs/session1/brief.md`. 건당 소요 시간은 인터뷰에서 확정하지 못해 이 문서에서는 "건당 3분 절감"을 가정으로 쓴다).
- 문제: 같은 "제7조"가 2013년 판과 2024년 판에서 다른 답(3영업일 vs 7영업일)이라 판본을 가리지 못하면 틀린 답이 나간다. 상담사가 찾는 시간과 틀린 판을 읽는 위험이 동시에 있다.
- 이번 PoC 범위: 공시된 약관·설명서 51건을 대상으로, 질문에 **근거 조항과 시행일을 붙여** 답하고 근거가 없으면 거절하는 상담사 보조 API 한 개. 범위 밖: 고객 직접 응대, 개인 계약 조회, 거래 실행, 해지환급금처럼 산출방법서가 필요한 계산.

| 배포 형태 | 컨테이너 셋: Qdrant(벡터 DB) · API(FastAPI, `/ask` · `/ask/stream`) · UI(nginx). 검색·리랭킹은 로컬, LLM 만 외부 API | `docker-compose.yml` |

## 3. 성능 (같은 문항 40개, 같은 자로 측정)

| 단계 | Recall@5 | MRR | 평균 지연 |
|---|---|---|---|
| Baseline (Dense) | 77.5% | 0.555 | 281ms |
| Hybrid (BM25+RRF+Rerank) | 77.5% | 0.693 | 1,311ms |
| Agentic (자기교정+Tool) | 85.0% | 0.734 | 11,821ms (p95 22,601ms) |

출처 `results/compare.csv` 의 `전체` 행, 2026-10-13.

유형별로 어디가 올랐는지 한 줄: 메타데이터형(판본·문서 종류를 가려야 하는 질문)이 MRR 0.50 → 0.45 → **1.00** 으로 가장 많이 올랐고(Self-Query 필터), 계산형이 0.30 → 0.80 → 0.80(Kiwi BM25 가 숫자·사전 낱말을 잡음), 조항번호형은 0.75 → 0.83 → **0.59** 로 Agentic 에서 유일하게 내려갔다(질문 재작성이 조항번호 토큰을 약하게 만든다. 다음 단계 1순위). `docs/eval_report.md`.

거절 지표 (둘을 같이 본다, `results/agentic.json`):
- 미답변 정확도(거절해야 할 것을 거절): **1.0** (2/2. 둘 다 "근거 부족"으로 한계를 밝힘)
- 오거절률(답할 수 있는데 거절): **5.3%** (38문항 중 2건. 둘 다 필터가 문서 종류를 잘못 뽑아 0건이 난 경우)

답변 품질(LLM-as-Judge, 사람 라벨 17개와 완전 일치 35% · ±1 이내 59%): 20문항 평균 3.74/6, 만점 4, 0점 3 (`results/judge.json`, `judge_calibration.json`). 적대적 5문항 중 4 통과, 실패 1은 범위만 공시된 이율을 단정한 "확신 유도" (`results/adversarial.json`).

## 4. 계산 정확도

문서에 인쇄된 예시값 대비: **9 / 15** 문항 일치 (`results/calc_e2e.json`, 2026-10-13)
절사 규칙에 따라 답이 갈리는 문항: 2건 (C05 단리식 세전, C12 의원 공제금액 5세대 기준. 규칙을 명시하면 정답 처리)
나머지 6건: 5건은 파라미터를 문서에서 못 찾아 **계산하지 않음**(숫자를 만들지 않았다), 1건(C07 연체이자)은 추출된 값이 0 으로 들어가 틀린 값이 나갔다. 계산 함수 자체의 오류는 0건(골든 테스트 32개 통과).

## 5. 한계 — 지금 못 하는 것

1. 해지환급금은 약관 제34조가 산출방법서를 참조하므로 계산하지 않고 "해당 금융회사 확인"으로 안내한다 (C13, S02 류).
2. HWP·HWPX 2건과 전 페이지가 깨진 PDF 1건은 인덱싱되지 않고 사람 검토 큐에 있다. 금감원 2022년 예금거래기본약관 HWPX 가 그중 하나라 2022 판 질문은 답하지 못한다 (`data/ingest_report.json` failed).
3. 질문에 연도·세대·발행사가 없으면 필터 기본값이 없어 판본이 섞이거나 오거절이 난다(필터 정확도 어긋남 5건 `results/filter_accuracy.json`, 오거절 2건). 이름·주소는 PII 마스킹 대상이 아니다(보안 답변서 Q1).
